One funny single-line sport the Olympics rejected — entry for the
[Rejected Olympic Sports](https://make.fun/bounty/u-motasimfuad-rejected-olympic-sports-9d83e7da)
bounty on [make.fun](https://make.fun), $2 in USDC.

## The entry

> Synchronized sighing: two athletes exhale in perfect unison while judges deduct points for sounding relieved.

109 characters — a made-up event, real enough to sound like a broadcast,
absurd enough to be funny, and short enough to quote.

## Run

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`)
and prints it. Python 3.13, standard library only, deterministic, no network.
